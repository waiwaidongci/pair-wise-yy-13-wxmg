# hxyfront-62012 纺织染整小样管理 · 留样分片台

源提示词编号：7

纺织染整实验室的留样分片台：每批小样按色差、耐水洗、手感（可增选耐摩擦）等检测项目剪出独立布条，登记剪样位置、尺寸、剪样人与母样余量，复核时按位置找回布条。

## 核心规则

- 三片宽度合计超过母样，或任何项目未剪样/未检测 → 不能出具整批结论
- 复测必须换人，只替换该片结果，其余布条结论不受影响
- 三片全部确认合格 → 才能判定批次通过
- 改剪尺寸或调整检测项目 → 相关布条失效、整批结论作废，旧布条归档仍可追溯
- 列表按客户订单关键词与结论状态筛选，展开可查每片位置、尺寸与复核记录

## 分层职责

- `src/domain/splitting.ts` —— 分片规则：纯类型与纯函数，所有写操作的校验与判定
- `src/archive/store.ts` —— 留样存档：localStorage 持久化与初始留样数据，不含规则
- `src/ui/` + `src/App.tsx` —— 页面操作：筛选、展开、表单与弹窗，只通过规则层改数据
