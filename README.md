# hxyfront-62012 纺织染整小样管理 · 留样分片台

源提示词编号：7

每批小样按检测项目（色差 / 耐水洗 / 手感，可配置）剪出独立布条，登记剪样位置、尺寸、检验人并核算母样余量。

## 判定规则

- 各片尺寸合计超过母样 → 超裁，禁止给出整批结论
- 任一检测项目未检测 → 不出整批结论
- 复测必须更换检验人，且只替换该片结果
- 全部项目确认合格 → 整批通过
- 修改剪样尺寸或检测项目 → 相关布条与整批结论失效，旧布条转入存档仍可追溯

## 分层

- `src/domain/slicing.ts` — 分片规则：裁剪布局、余量核算、结论推导、复测校验（纯函数）
- `src/store/archive.ts` — 留样存档：localStorage 持久化、种子数据、变更操作
- `src/ui/*` + `src/App.tsx` — 页面操作：筛选、展开、登记、规则编辑
